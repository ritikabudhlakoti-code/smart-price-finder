# Smart Price Finder

Smart Price Finder is a simple product search application built using HTML, CSS, and JavaScript.

It allows users to enter a target price and find the products whose prices are closest to the entered amount.

## Features

- Search products by target price
- Find the closest matching products
- Display product name
- Display brand
- Display product price
- Display product rating
- View product details
- Responsive product card layout
- Simple and clean user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
